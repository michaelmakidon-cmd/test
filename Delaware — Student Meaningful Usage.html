How to read this & methodology
  • Meaningful usage = a student logged in at least the selected number of times (default ≥4) in a calendar month. Default view is grades 3–12; use the K–2 band to show younger grades against the same 85% goal.
  • Denominator = NCES enrollment for the grade. Where logins exceed reported enrollment, the value is capped at 100% per grade before any totalling. This happens because NCES enrollment is an annual state-reported figure that can lag ClassLink's live active-account count (student mobility, mid-year enrollment, grade mapping).
  • Pooled (raw) totals sum all qualifying students ÷ sum all enrollment — the recommended default, so small schools don't distort the statewide figure. Avg of % averages each district/grade's percentage equally, for comparison only.
  • Reduced-usage months — the summer lead-in (Jul–Aug) and the year-end taper (Jun) — are shown on the trend graph in gray for seasonal context but excluded from the usage calculation by default (KPIs, the instructional average, and the breakdown table). This keeps the "latest month" and averages reflecting the operating school year rather than the calendar bookends. Re-check any of these under "Months counted" to include them.
  • Suppress cells <10 masks any displayed value backed by fewer than 10 enrolled students. Pooled totals always use the raw underlying counts.
  • Figures reflect apps and logins accessed through ClassLink.
